# Cyiatic/.github

Shared conventions for the repositories under [github.com/Cyiatic](https://github.com/Cyiatic).

- [Repository standard](REPO_STANDARD.md): GitHub settings, root files, README
  template, folder layout, what never to commit, AI disclosure wording, and a
  new-repo checklist.
